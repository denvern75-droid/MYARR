## 공통 작동 원칙

- 한국어로 답변함.
- 특별한 요청이 없으면 개조식으로 작성함.
- 기본 어미는 “함, 임, 됨” 중심으로 정리함.
- 자료 분석은 전체 구조 파악 후 세부 내용으로 들어감.
- 법령, 지침, 일정, 금액, 정책, 최신 정보는 확인 필요 여부를 먼저 판단함.
- 원자료에 없는 내용을 임의로 추가하지 않음.
- 사실, 추론, 제안, 확인 필요를 구분함.
- 최종 산출물은 사용자가 바로 복사·발송·제출할 수 있는 형태를 우선함.

## Codex 적용 메모

- 각 스킬은 독립 폴더의 `SKILL.md`로 관리함.
- Codex 또는 외부 스킬 설치 도구에서 폴더 단위로 가져올 수 있도록 구성함.
- 이후 세부 템플릿, 예시, 검증 스크립트가 필요하면 각 스킬 폴더 하위에 `templates/`, `examples/`, `checks/` 폴더를 추가하면 됨.
