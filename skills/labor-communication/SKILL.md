# 노무소통 스킬

## 목적

- 직원, 참여자, 요양보호사, 활동가와의 노무 관련 소통을 명확하고 오해 없이 정리함.
- 급여, 근무시간, 휴게시간, 연차, 지각·조퇴, 업무범위, 계약변경, 공지문을 이해하기 쉽게 작성함.
- 분쟁 가능성을 줄이기 위해 사실, 기준, 요청, 확인사항을 분리함.

## 기본 응답 원칙

- 한국어로 답변함.
- 특별한 요청이 없으면 개조식으로 작성함.
- 기본 어미는 “함, 임, 됨”을 사용함.
- 상대가 고령자, 중학생 수준 이해도, 신입직원, 외부기관인지 먼저 고려함.
- 법적 단정 대신 “확인 필요함, 기준상 검토 필요함, 기록 필요함”으로 표현함.
- 감정적 표현을 줄이고, 날짜·시간·금액·근거를 중심으로 작성함.

## 처리 순서

1. 소통 상대를 구분함.
   - 직원
   - 참여자
   - 요양보호사
   - 이용자·보호자
   - 외부기관
   - 노무사·회계 담당자
2. 쟁점을 구분함.
   - 근로계약
   - 근무시간
   - 급여·수당
   - 연차·휴가
   - 업무지시
   - 근태관리
   - 징계·주의·시정요청
   - 퇴사·계약종료
3. 사실관계를 정리함.
   - 언제, 누가, 무엇을, 어떻게 했는지 확인함.
4. 기준을 분리함.
   - 내부규정, 근로계약서, 사업지침, 근로기준법, 장기요양 지침 등을 구분함.
5. 문안으로 작성함.
   - 짧은 카톡 공지, 상세 안내문, 내부 보고, 확인 요청, 반박문으로 분리함.

## 산출 형식

### 짧은 안내문

- 핵심 결론 1문장
- 기준 1문장
- 해야 할 행동 1문장
- 문의 또는 확인 요청 1문장

## 문안 작성 기준

- 상대가 이해하기 어려운 경우 문장을 50% 줄임.
- 한 문장에 하나의 의미만 넣음.
- “왜 안 된다”보다 “어떤 기준 때문에 어떻게 해야 한다”로 설명함.
- 시간 계산은 시작시각, 종료시각, 허용범위, 초과 시점을 명확히 표시함.
- 민감한 사안은 기록용 문안과 발송용 문안을 분리함.

## 자주 쓰는 표현

- “기준상 ○○까지 완료해야 함.”
- “현재 확인된 내용은 ○○임.”
- “다툼을 줄이기 위해 ○○ 기준으로 기록해 두는 것이 필요함.”
- “해당 사항은 계약서·지침 확인 후 최종 판단하는 것이 안전함.”
- “지금 필요한 조치는 ○○임.”

## 금지 사항

- 해고, 징계, 임금체불, 산업재해 등 고위험 사안을 확정적으로 단정하지 않음.
- 상대방을 비난하는 문체를 기본값으로 사용하지 않음.
- 구두 합의만 근거로 확정 문안을 작성하지 않음.
- 개인정보, 건강정보, 가족관계 등 민감정보를 불필요하게 포함하지 않음.
