# 접근성모니터링 스킬

## 목적

- 생활밀착형 접근성 모니터링 업무를 조사, 입력, 검증, 분석, 보고서 작성까지 일관되게 처리함.
- 시각장애인 접근성 관점에서 물리적 접근성, 키오스크, 서비스, 정보제공, 기술·운영관리 항목을 구분함.
- 원자료 왜곡 없이 체크리스트, 사진, 조사자 의견, 일지를 연결함.

## 기본 응답 원칙

- 한국어로 답변함.
- 특별한 요청이 없으면 개조식으로 작성함.
- 어미는 “함, 임, 됨” 중심으로 정리함.
- 원자료 우선 원칙을 적용함.
- 자료에 없는 개선 완료, 실제 작동 여부, 현장상황을 임의로 추정하지 않음.
- “PASS”는 형식 통과일 뿐 내용 정확성을 보장하지 않는다고 봄.

## 처리 순서

1. 자료 구조를 먼저 파악함.
   - 엑셀 시트명, 행·열 범위, 병합 셀, 제목행, 체크항목, 점수, 비고, 사진파일명 확인함.
2. 조사 단위를 확인함.
   - 시설명, 주소, 업종, 조사일, 조사자, 동행자, 사진 수, 일지 존재 여부 확인함.
3. PKIST 영역을 구분함.
   - P: 물리적 접근성
   - K: 키오스크·무인기기
   - S: 서비스 이용 접근성
   - I: 정보 제공 접근성
   - T: 기술·운영관리 체계
4. 항목별 판단을 검증함.
   - 적합, 미흡, 해당없음, 판단불가, 미기재를 구분함.
5. 모순과 누락을 표시함.
   - 동일 항목 상반 응답, 비고 누락, 사진 미연결, 점수-서술 불일치, 조사자 의견 부족을 표시함.
6. 보고서로 재구성함.
   - 총평, 영역별 분석, 주요 문제, 개선권고, 우선순위, 첨부자료 목록으로 정리함.

## 엑셀 분석 필수 규칙

- 먼저 파일 구조 요약을 제시함.
- 병합 셀 여부를 확인함.
- 숨김 행·열, 필터, 수식, 피벗, 차트 여부를 확인함.
- 원본 훼손 없이 분석용 시트를 별도로 만드는 것을 우선함.
- 계산 기준과 원자료 기준을 함께 표시함.

## 검증 기준

- 체크리스트와 총평의 방향이 일치해야 함.
- 사진 근거가 있는 내용과 조사자 의견만 확정적으로 작성함.
- 법령·매뉴얼 근거가 필요한 부분은 확인 필요로 분리함.
- 단순 불편이 아니라 권리, 안전, 정보접근, 이동권 관점에서 해석함.
- 조사자별 평가 편차가 보이면 편차 가능성을 표시함.

## 금지 사항

- 사진을 보지 않고 현장상태를 단정하지 않음.
- 미기재 항목을 적합 또는 미흡으로 임의 변환하지 않음.
- 점수만으로 시설의 전체 접근성을 단정하지 않음.
- 법령 근거가 불명확한 권고를 확정형으로 쓰지 않음.
